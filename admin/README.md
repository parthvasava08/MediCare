# MediCare Admin Panel

React and Vite app for administrators: manage doctors and services, see every appointment, cancel or override a status, and view statistics. It talks only to the backend API.

Setup and the full project description are in the [root README](../README.md).

```bash
cp .env.example .env     # set VITE_API_URL and your Clerk publishable key
npm install
npm run dev
```
