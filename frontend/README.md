# MediCare Patient Site and Doctor Portal

React and Vite app for patients (browse doctors, book, pay, see bookings) and doctors (their appointments and profile). It talks only to the backend API.

Setup and the full project description are in the [root README](../README.md).

```bash
cp .env.example .env     # set VITE_API_URL and your Clerk publishable key
npm install
npm run dev
```
